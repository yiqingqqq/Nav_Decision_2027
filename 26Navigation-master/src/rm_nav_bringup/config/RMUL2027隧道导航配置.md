# RMUL 2027 隧道导航配置

## 生效范围

`bringup_sim.launch.py` 使用 `config/simulation/nav2_params_sim.yaml`。本次配置只修改该仿真参数文件，不修改 reality 和其他历史配置目录。

Nav2 的 `robot_radius` 表示圆形 footprint 的半径。本配置将局部、全局 costmap 和隧道控制器圆形 footprint 统一设为 `0.30 m`。

## 两套 TEB 控制器

| Controller ID | 最小障碍距离 | 速度 | 用途 |
|---|---:|---:|---|
| `FollowPath` | `0.35 m` | 原正常速度 | 普通场地区域和隧道入口前 |
| `TunnelController` | `0.04 m` | 平移 `0.30 m/s`、旋转 `0.50 rad/s` | 仅在隧道内使用 |

普通 TEB 的 `inflation_dist` 为 `0.35 m`，`weight_obstacle` 为 `50`。

隧道控制器的关键参数：

```yaml
TunnelController:
  plugin: teb_local_planner::TebLocalPlannerROS
  max_vel_x: 0.30
  max_vel_x_backwards: 0.20
  max_vel_y: 0.30
  max_vel_theta: 0.50
  dt_ref: 0.15
  global_plan_overwrite_orientation: false
  allow_init_with_backwards_motion: false
  max_global_plan_lookahead_dist: 1.5
  global_plan_viapoint_sep: 0.20
  via_points_ordered: true
  min_obstacle_dist: 0.04
  inflation_dist: 0.10
  penalty_epsilon: 0.01
  dynamic_obstacle_inflation_dist: 0.10
  no_inner_iterations: 5
  no_outer_iterations: 4
  weight_obstacle: 30.0
  weight_viapoint: 20.0
  enable_homotopy_class_planning: false
```

局部和全局 costmap 的 `inflation_layer` 暂时保持原值；控制器切换只改变 TEB 的速度和障碍距离约束。

## 选择机制

Nav2 使用 `navigate_to_pose_with_controller_selector.xml`。决策层在发送每段目标前，通过现有 `/controller_selector` 选择 `FollowPath` 或 `TunnelController`；Nav2 先读取该选择，再生成全局路径。不新增话题、消息或服务。

每段全局路径生成后，只有在目标更新或当前路径已失效时才重新规划，避免在隧道入口停顿后主动改走大路。

决策项目的 `TraverseTunnelOutbound` 自动执行：

```text
根据当前位置选择较近端点作为入口
  → 用 FollowPath 导航到入口并对齐隧道方向
  → 选择 TunnelController
  → 导航到隧道内部强制点
  → 导航到另一端出口
  → 恢复 FollowPath
```

场地绝对路线 `(5.0, -3.0) → (4.0, -3.6) → (2.5, -3.6) → (0.5, -3.6)` 使用出生位姿 `(5.0,-3.0,π)` 转换到序列化地图的局部 `map` 坐标：

```text
(0.0, 0.0) → (1.0, 0.6) → (2.5, 0.6) → (4.5, 0.6)
```

场外侧进入时的 `map` 朝向为 `0`。反向通过时自动交换入口和出口，朝向为 `π`。隧道判定矩形为 `x=[1.3,3.7]`、`y=[0.2,1.0]`。

仅使用 RViz Nav2 Goal 时没有决策层的隧道三段路线，默认使用 `FollowPath`。如需独立验证隧道控制器，先通过现有话题选择：

```bash
ros2 topic pub --once /controller_selector std_msgs/msg/String "{data: TunnelController}"
```

## 构建与验证

```bash
cd ~/Robotics/RM/Nav_Decision/26Navigation-master
source /opt/ros/humble/setup.bash
colcon build --symlink-install --parallel-workers 1
source ./install/setup.bash
```

启动后检查：

```bash
ros2 param get /local_costmap/local_costmap robot_radius
ros2 param get /global_costmap/global_costmap robot_radius
ros2 param get /controller_server controller_plugins
ros2 param get /controller_server FollowPath.min_obstacle_dist
ros2 param get /controller_server TunnelController.min_obstacle_dist
ros2 param get /controller_server TunnelController.inflation_dist
```

预期分别得到 `0.32`、`0.32`、包含两个 Controller ID、`0.35`、`0.04` 和 `0.10`。
